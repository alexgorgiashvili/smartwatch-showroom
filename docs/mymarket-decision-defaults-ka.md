# MyMarket Decision Defaults

ეს არის რეკომენდებული default გადაწყვეტილებები, თუ ოპერატორისგან დამატებითი პასუხი ჯერ არ მიგვიღია.

## რეკომენდებული defaults

1. Q19 discount
- თუ live source ადასტურებს discount-ს, საბოლოო ფასი იყოს 59 ლარი
- თუ live source discount-ს აღარ ადასტურებს, listing დაიდოს ჩვეულებრივ ფასად და preview-ში ეს განსხვავება გამოჩნდეს

2. CT23 discount
- თუ live-ში discount არ ჩანს, პროდუქტი დაიდოს ჩვეულებრივ ფასად
- ძველი ჩანაწერი არ ჩაითვალოს საკმარის საფუძვლად

3. T53 gift-box messaging
- რეკომენდებულია “სასაჩუქრე ბოქსი” ჩაჯდეს სათაურშიც და აღწერაშიც
- მიზეზი: ამ მოდელის ყველაზე გამორჩეული კომერციული კუთხე სწორედ gift positioning-ია

4. KT34 Android messaging
- რეკომენდებულია “Android” ჩაჯდეს სათაურში
- მიზეზი: ეს არის მოდელის ყველაზე მკაფიო განმასხვავებელი ნიშანი

5. Publish approval behavior
- რეკომენდებულია აგენტმა preview-ის შემდეგ დაელოდოს approval-ს
- approval-ის მიღების შემდეგ აგენტმა თვითონ დაასრულოს publish პროცესი ბოლომდე
- დამატებითი ხელით ბოლო click საჭირო არ არის, თუ preview დამტკიცებულია

## რატომ ვირჩევთ ამ defaults-ს

- პროცესს ნაკლებად აჩერებს
- აგენტს აძლევს მკაფიო ოპერატორულ წესს
- ამცირებს თვითნებური ინტერპრეტაციის რისკს
- უკეთ ერგება reusable workflow-ს შემდეგი batch-ებისთვისაც
